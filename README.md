# RachaAí - Dashboard Financeiro

## Objetivo

Criar um dashboard financeiro utilizando Blazor e C# aplicando conceitos de IHC e UX.

## Funcionalidades

- Cards de resumo financeiro
- Lista de grupos
- Componente reutilizável GrupoCard
- Responsividade com Bootstrap
- Feedback visual com cores

## Implementação

A hierarquia visual foi criada utilizando Bootstrap e componentização com Blazor.

O componente GrupoCard foi desenvolvido para reutilização dos grupos financeiros.

As cores verde e vermelha ajudam o usuário a identificar rapidamente créditos e dívidas.

## Dificuldade Técnica

A maior dificuldade foi realizar a componentização e o envio de parâmetros entre componentes Blazor.
